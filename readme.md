# Spotify Plus Extensions

This is a collection of extensions that bring the functionality of the original Spotify Plus back. These are all fairly small, so I'm grouping them all into one repo. If there was a feature from the original Spotify Plus that you liked, it's probably in here!

### Bring Back Likes

This extension brings the like button back! It replaces whatever the plus button is with the original like button. Just as it was meant to be. Why did Spotify remove the like button, I'm really not sure.

### Play Next

Adds a new button to Spotify that lets you add songs directly to the up next queue instead of the normal queue. This lets the song persist in the queue even after the song finishes, meaning you can skip back to it even after the song finishes.

### Persistent Private Session

If you like having private session on, it's probably rather annoying that it turns off every 6 hours. This extension will keep it on permanently.

### Custom Sleep Timers

This extension allows you to create custom sleep timers. You can remove the default ones, add new ones, reorder them, or whatever you want to do, or you can set one time timers. You'll have complete control over your sleep timers.

### Last.fm Stats

If you enter your Last.fm username in the settings, this extension will show you how many scrobbles you have on any song, album, or artist. Open the context menu for any of those, and it will tell you in the header.
