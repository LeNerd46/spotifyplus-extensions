# Last.fm Scrobbles

Last.fm Scrobbles is an extension for Spotify Plus that will display your scrobble count for songs, albums, and artists. Open the context menu for any item, and it will show you how many scrobbles you have in the header of the context menu.

Make sure you set your username in settings!
