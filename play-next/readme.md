# Play Next

Play Next is an extension for Spotify Plus that adds a new button to the context menu. Pressing this button will add a button to the queue. But instead of the song going away after it's done, it will remain in the play history after it's finished. So when the song is done, you can skip back to it. With the normal Spotify queue, the song would just disappear if you tried skipping back to it.
